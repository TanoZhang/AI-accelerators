# APB Register Map

## APB behavior

The block is a 32-bit APB4 slave with 12-bit byte addresses and `PSTRB[3:0]`. All registers are word aligned. `PREADY` is always high, so a transfer completes in the access phase when `PSEL && PENABLE` is true.

Reads from unmapped or unaligned addresses return zero and assert `PSLVERR`. Invalid writes assert `PSLVERR` and have no effect. Writes to read-only registers also assert `PSLVERR`. Reserved fields read as zero and ignore writes. Configuration writes honor byte strobes.

## Register summary

| Offset | Name | Access | Reset | Description |
|---:|---|:---:|---:|---|
| `0x00` | `CONTROL` | RO/W1P | `0x0000_0000` | Start and soft-reset commands |
| `0x04` | `STATUS` | RO | `0x0000_0000` | Accelerator status |
| `0x08` | `M` | RW | `0x0000_0000` | Output rows |
| `0x0C` | `N` | RW | `0x0000_0000` | Output columns |
| `0x10` | `K` | RW | `0x0000_0000` | Reduction dimension |
| `0x14` | `SRC_A_ADDR` | RW | `0x0000_0000` | Source A byte address |
| `0x18` | `SRC_B_ADDR` | RW | `0x0000_0000` | Source B byte address |
| `0x1C` | `DST_ADDR` | RW | `0x0000_0000` | Destination byte address |
| `0x20` | `QUANT_CONFIG` | RW | `0x0000_0000` | Quantization and ReLU controls |
| `0x24` | `INT_ENABLE` | RW | `0x0000_0000` | Interrupt enables |
| `0x28` | `INT_STATUS` | RO/W1C | `0x0000_0000` | Sticky interrupt status |
| `0x2C` | `PERF_CYCLES` | RO | hardware | Total command cycles |
| `0x30` | `PERF_MAC_CYCLES` | RO | hardware | Cycles with `mac_en=1` |
| `0x34` | `PERF_COMPUTE_CYCLES` | RO | hardware | Compute-active cycles |
| `0x38` | `PERF_DMA_CYCLES` | RO | hardware | DMA-active cycles |
| `0x3C` | `PERF_STALL_CYCLES` | RO | hardware | Compute or DMA stall cycles |

`W1P` is a one-cycle pulse generated by writing one. `W1C` clears a sticky bit by writing one.

## Register fields

### `CONTROL` (`0x00`)

| Bits | Field | Access | Description |
|---:|---|:---:|---|
| 0 | `START` | W1P | Generate `start_pulse` |
| 1 | `SOFT_RESET` | W1P | Generate `soft_reset_pulse` |
| 31:2 | Reserved | - | Read zero |

The command bits always read zero. Soft reset is a command to accelerator hardware; it does not alter configuration or interrupt registers inside this block.

### `STATUS` (`0x04`)

| Bits | Field | Access | Description |
|---:|---|:---:|---|
| 0 | `BUSY` | RO | Live hardware busy state |
| 1 | `DONE` | RO | Mirrors sticky `INT_STATUS.DONE` |
| 2 | `ERROR` | RO | Mirrors sticky `INT_STATUS.ERROR` |
| 31:3 | Reserved | - | Read zero |

### Dimensions (`0x08`-`0x10`)

Bits `DIM_W-1:0` hold the unsigned dimension. The default `DIM_W` is 16. Other bits read zero.

### Address registers (`0x14`-`0x1C`)

All 32 bits hold an external byte address. Alignment validation is performed by the accelerator when a job starts.

### `QUANT_CONFIG` (`0x20`)

| Bits | Field | Access | Description |
|---:|---|:---:|---|
| 0 | `QUANT_ENABLE` | RW | Enable arithmetic right shift |
| 1 | `RELU_ENABLE` | RW | Enable ReLU before shifting |
| 6:2 | `QUANT_SHIFT` | RW | Shift amount from 0 through 31 |
| 31:7 | Reserved | - | Read zero |

When quantization is disabled, the shift is bypassed. ReLU and INT8 saturation remain active in the output formatter.

### `INT_ENABLE` (`0x24`)

| Bits | Field | Access | Description |
|---:|---|:---:|---|
| 0 | `DONE` | RW | Enable completion interrupt |
| 1 | `ERROR` | RW | Enable error interrupt |
| 31:2 | Reserved | - | Read zero |

### `INT_STATUS` (`0x28`)

| Bits | Field | Access | Description |
|---:|---|:---:|---|
| 0 | `DONE` | RO/W1C | Sticky hardware completion event |
| 1 | `ERROR` | RO/W1C | Sticky hardware error event |
| 31:2 | Reserved | - | Read zero |

Hardware events set their bits. Software clears bits by writing one with `PSTRB[0]` asserted. A hardware set wins over a simultaneous software clear. The interrupt output is:

```text
irq = |(INT_STATUS & INT_ENABLE)
```

### Performance counters (`0x2C`-`0x3C`)

These read-only registers expose the five 32-bit saturating counters supplied by `perf_counters`. The register block does not modify or clear them. A newly accepted command clears the old values and counts its acceptance edge as `PERF_CYCLES=1`. The successful-completion or error edge is also counted, then all values remain unchanged until the next accepted command.

- `PERF_CYCLES` increments on every active command cycle.
- `PERF_COMPUTE_CYCLES` increments when `compute_active=1`.
- `PERF_MAC_CYCLES` increments when `mac_en=1`.
- `PERF_DMA_CYCLES` increments when `dma_active=1`.
- `PERF_STALL_CYCLES` increments once when either an active compute operation or an active DMA operation is blocked by ready/valid backpressure. Simultaneous compute and DMA stalls still add one because this counter measures wall-clock cycles.

Each condition is sampled on the rising edge. Qualifying activity on the accepted START or terminal edge contributes to its corresponding counter. At `0xFFFF_FFFF`, a counter remains saturated and never wraps.
